# TaskMate AI

 https://taskmate-ai.onrender.com

Upload any project brief. Gemini AI creates a complete team plan in seconds.

## What it does
- Upload a project brief (PDF, PNG, JPG)
- Gemini AI analyzes it
- Get: Tasks breakdown, Team roles, Weekly timeline

## How to use
1. Upload your project brief
2. Click "Generate team plan"
3. Done!

## Built with
- HTML, CSS, JavaScript
- Google Gemini API
